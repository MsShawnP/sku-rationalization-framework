# CSS design token drift in Lailara projects

**This convention has moved.** Its `applies_when` covers every Lailara design
system project, so it is no longer maintained here.

**Canonical location:** `reference/lailara-design-system/css-design-token-drift.md`

Kept as a pointer per `reference/prevention-rule-scoping.md`: a rule is scoped
to the surface it governs, not the repo that learned it. A portfolio-wide
convention held in one repo's `conventions/` folder is reachable only from that
repo — which is the failure the rule itself names.

No repo-specific instance of this convention has been recorded for
sku-rationalization-framework. If one is found, record it here and link the
canonical statement above.
