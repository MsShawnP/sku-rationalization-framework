# SKU Rationalization Framework

A multi-dimensional SKU scoring framework for specialty food brands at $10M–$30M
revenue. Scores every SKU across velocity, contribution margin, shelf-space cost,
production complexity, and cannibalization risk to identify which SKUs to kill,
fix, maintain, or double down on.

## What it does

Given a brand's SKU portfolio data, the framework produces a four-quadrant
classification per SKU and a kill list with quantified annual savings. The
Cinderhaven case study applies the framework to a 90-SKU portfolio and identifies
$110K/year in loaded costs above contribution on the bottom 15 SKUs.
